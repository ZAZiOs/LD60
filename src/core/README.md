# Core Library (`src/core`)

Ядро движка игры **tech_plague** (LÖVE 11.5+).

Полная подробная документация с примерами кода и рецептами находится в файле:
👉 **[docs/CORE.md](../../docs/CORE.md)**

## Краткий обзор модулей:

| Модуль | Файл | Назначение |
|---|---|---|
| **Viewport** | `viewport.lua` | Виртуальное разрешение 1920x1080, авто-масштабирование (letterbox), конвертация координат мыши |
| **SceneManager** | `scene_manager.lua` | Управление сценами, плавные переходы (fade), передача ввода |
| **AudioManager** | `audio_manager.lua` | Фоновая музыка с preloop + loop, кроссфейды, полифонические звуки (SFX) |
| **I18n** | `i18n.lua` | Локализация (ru/en) и система управления шрифтами (пресеты, начертания) |
| **Spritesheet** | `spritesheet.lua` | Сетка кадров и именованные спрайты по INI |
| **Animation** | `animation.lua` | Продвинутый плеер покадровой анимации (очередь, лупы, пинг-понг) |
| **SpritesheetManager** | `spritesheet_manager.lua` | Кеширование спрайтшитов и фабрика аниматоров |
| **IniParser** | `ini_parser.lua` | Парсер `.ini` файлов кадров и анимаций |
| **GameState** | `game_state.lua` | Глобальное состояние игры (день, время суток, баланс, флаги) |
| **Settings** | `settings.lua` | Настройки звука, дисплея и локали с сохранением в `settings.json` |
| **Events** | `events.lua` | Глобальная шина событий (Pub/Sub) с тегами очистки |
| **Config** | `config.lua` | Базовые константы окна и виртуального холста |
